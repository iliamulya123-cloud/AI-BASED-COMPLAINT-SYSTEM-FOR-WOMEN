# AI-BASED-COMPLAINT-SYSTEM-FOR-WOMEN
A secure Django-based web portal for women's safety featuring AI-powered fake complaint detection and integrated voice-to-text reporting
📖 Overview
The AI-Based Smart Complaint System for Women is a specialized web application built using Django and Bootstrap. It aims to provide a safe, accessible, and intelligent environment for women to file complaints.The system goes beyond simple form submission by using Natural Language Processing (NLP) to analyze the sentiment and structure of the complaint, helping authorities identify and prioritize genuine cases while filtering out potential spam or fake reports.
✨ Key Features
🎤 Voice-to-Text Integration: Users can record their complaints verbally; the system transcribes them into text using the Web Speech API.🤖 AI Fake Complaint Detection: An integrated AI engine evaluates the emotional tone and length of the report to flag suspicious or "too-short" entries.
📂 Structured Reporting: 
Categorizes complaints into specific types (e.g., Harassment, Cyberbullying, Domestic Violence) for better organization.
🔒 Secure Backend: Built with Django to ensure data integrity, CSRF protection, and secure database management.
📱 Responsive UI: A clean, modern, and empathetic interface designed with Bootstrap 5 for mobile and desktop accessibility.
